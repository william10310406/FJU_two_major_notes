# Computer Organization
## Computer
- Central Processing Unit (CPU)
- Main Memory





## CPU & BUS
### CPU
- Control Unit （主控）
    - Sequencing Logic
    - Control Unit Registers and Decoders
    - Control Memory
-  Arithme 算數＆邏輯運算

### BUS（匯流排）
- Address Bus傳記憶體位置
- Data Bus 傳輸資料
- Control Bus 傳輸命令

## CPU 種類
- CPU: 中央處理器（單元）
- GPU: 圖形處理器（單元），顯示卡上
    - 算浮點數快
    - 繪圖運算
    - 深度學習&機器演算法
    - 接收 CPU 發送的指令後執行
- NPU: 神經網路處理器（單元）
- TPU: 張量(tensor)處理器（單元）
    - 加速機器學習的處理器
    - 低精度計算

## CPU | Cache | Memory | Hard-Disk
- 速度：快 -> 慢
- 容量：小 -> 大（不含CPU）
- 成本：高 -> 低
